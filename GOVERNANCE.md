# Governance

Crossing Guard is maintained by the crossing-guard GitHub account. Maintainers decide
which changes are accepted and when a release is ready. Contributions and questions are
welcome through repository issues and pull requests; acceptance is not guaranteed.

Discuss substantial behavior or interface changes before implementing them. Explain the
user journey, compatibility impact, alternatives and verification. Maintainers may request
revisions or defer proposals. Published source will become the authority for published
behavior; private development activity does not imply a public release commitment.

See [contributing](CONTRIBUTING.md), [conduct](CODE_OF_CONDUCT.md) and
[release policy](docs/release-policy.md). Report security issues privately through
[SECURITY.md](SECURITY.md).
