# Support

The first alpha is in preparation. Downloads and verified platform/client coverage will
be listed in its release notes when published.

General project questions: [repository issues](https://github.com/crossing-guard/crossing-guard/issues)
or crossingguarddev@gmail.com. There is no guaranteed response
time or paid-support commitment. Use [SECURITY.md](SECURITY.md) for vulnerabilities.

Bug reports should include the exact version, operating system, client, reproduction and
relevant error. Redact secrets and personal data. Do not attach whole memory stores,
databases, source trees or transcripts by default.
